# **The Draft Room Tip Calculator**

## **Description**  
The Draft Room Tip Calculator is a proprietary tool designed to automate and simplify the allocation of tips among employees. It ensures accuracy, eliminates manual errors, and provides clear reporting for management.

---

## **Features**  
- **Tip Distribution**: Automatically allocates cash and credit card tips based on payable hours.  
- **3% Deduction Toggle**: Optionally deducts 3% for operational costs.  
- **Excel/CSV Upload**: Drag and drop an Excel/CSV file to import employee data.  
- **Custom Reports**: Generate detailed Excel-based tip allocation reports.  
- **User-Friendly Interface**: Clean layout for easy navigation and operation.  

---

## **Installation**  
1. Download all project files.  
2. Ensure the following structure:  
   - `index.html`  
   - `script.js`  
   - `css/sb-admin-2.min.css`  
   - `vendor/fontawesome-free/` (for icons)  

3. Open `index.html` in a modern browser.  

---

## **Usage**  
1. **Input Tips**: Enter total cash and credit card tips.  
2. **Add Employees**: Enter employee details (or upload via Excel).  
3. **Distribute Tips**: Click **"Distribute Tips"** to calculate and allocate tips.  
4. **Generate Reports**: Export results using the **"Generate Report"** button.  
5. **Clear Table**: Reset all data using the **"Clear Table"** button.
